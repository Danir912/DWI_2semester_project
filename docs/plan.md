# План разработки

## Цель проекта

Contact CRM — учебное Angular-приложение для ведения контактов, истории взаимодействий,
заметок и напоминаний о следующих касаниях. Основной фокус прототипа — дать менеджеру
быстрый обзор базы, возможность найти нужный контакт и сразу зафиксировать новое действие.

Проект строится как SPA с mock API, авторизацией, защищёнными маршрутами и состоянием на
Signal Store.

## Пользовательские сценарии

1. Менеджер входит в приложение и видит список контактов с ключевой статистикой.
2. Менеджер создаёт или редактирует контакт с компанией, категорией, статусом и датой follow-up.
3. Менеджер ищет и фильтрует контакты по статусу, категории и текстовому запросу.
4. Менеджер фиксирует звонок, встречу, письмо, заметку или напоминание в карточке контакта.

## Этапы разработки

| Срок | Задача |
|------|--------|
| До конца апреля | Инициализация Angular 21, routing, базовая структура core/shared/features, формы |
| До конца мая | Mock API, авторизация, CRM state, CRUD контактов, фильтрация, Taiga UI |
| За начало июня | Unit и component tests, CI, README, адаптивная верстка, финальная проверка |

## Риски

1. Несовместимость версий Angular 21 и UI-зависимостей — закреплять версии и проверять build.
2. Недостаток времени на полный backend — использовать json-server и типизированные сервисы.
3. Слишком широкий CRM-функционал — оставить один основной рабочий экран с главными сценариями.
4. Недостаточное покрытие тестами — покрыть фильтрацию/статистику unit-тестами и happy path в Playwright.
5. Формальное использование Taiga UI — применить библиотеку в формах, кнопках, loader, badges и segmented control.
